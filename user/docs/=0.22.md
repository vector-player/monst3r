# Explanation of TEST_RUN_STATUS.md

## Overview

`TEST_RUN_STATUS.md` is a real-time status tracking document for MonST3R test runs. MonST3R appears to be a 3D reconstruction system that processes image sequences to generate 3D models, camera trajectories, depth maps, and other outputs.

## Purpose

This document serves as a **live status report** that tracks:
- The progress of a MonST3R inference run
- System resource usage (CPU, memory)
- Processing speed and estimated completion time
- Configuration details for the current run
- Expected outputs and monitoring commands

## Document Structure

### 1. Header Section
- **Started:** Timestamp when the test run began
- **Status:** Current state indicator (🟢 RUNNING, ✅ COMPLETE, ❌ FAILED, etc.)

### 2. Test Configuration
Documents the input parameters:
- Input directory (source images)
- Output directory (where results will be saved)
- Processing mode (batchified vs non-batchified)
- Environment details
- Process ID for system monitoring

### 3. Progress Tracking
Divided into:
- **Completed Steps:** Checkmarked items that have finished
  - Model loading (from Hugging Face)
  - Image loading and preprocessing
  - Inference progress (with percentage and batch counts)
- **Current Status:** Real-time metrics
  - Batch completion progress
  - Processing speed (iterations per second)
  - Resource usage (RAM, CPU)
  - Runtime duration

### 4. Next Steps
Lists upcoming processing stages:
- Flow precomputation
- Global optimization
- Output file generation

### 5. Monitoring Section
Provides shell commands to:
- View live logs (`tail -f`)
- Check if the process is running (`ps aux`)
- Inspect output files when complete (`ls`)

### 6. Expected Output Files
Documents what files will be generated:
- Trajectory files (`pred_traj.txt`)
- Camera intrinsics (`pred_intrinsics.txt`)
- Depth maps directory
- Dynamic masks directory
- Confidence maps
- RGB images
- 3D model files (`.glb` format)

### 7. Notes Section
Contains important observations:
- Fixes applied (e.g., SAM2 checkpoint)
- Performance notes
- Error status
- Estimated total completion time

## How to Use This Document

1. **During a Run:** Check the "Current Status" section to see real-time progress
2. **Monitoring:** Use the provided shell commands to verify the process is running
3. **Troubleshooting:** Review the Notes section for known issues or fixes
4. **Verification:** After completion, use the "Expected Output Files" section to verify all outputs were generated

## Key Concepts

- **MonST3R:** A 3D reconstruction model/system
- **Inference:** The process of running the model on input images
- **RoPE2D:** A positional encoding method (document notes using slow PyTorch version)
- **Flow precomputation:** Optical flow calculation between frames
- **Global optimization:** Final refinement step for 3D reconstruction
- **SAM2:** Segment Anything Model 2, used for segmentation

## Typical Workflow

1. Start a MonST3R test run
2. This document is created/updated with initial configuration
3. As the run progresses, status sections are updated
4. User monitors progress using this document and shell commands
5. After completion, outputs are verified against the expected files list
