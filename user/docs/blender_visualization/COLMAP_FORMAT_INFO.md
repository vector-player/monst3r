# COLMAP Format in MonST3R Output

## ❌ Answer: No COLMAP Files

**MonST3R does NOT export COLMAP format files.**

## 📁 What MonST3R Actually Exports

MonST3R generates the following output files:

### Text Files
- `pred_traj.txt` - Camera trajectory in **TUM format**
  - Format: `timestamp tx ty tz qx qy qz qw`
  - Contains camera poses (position + quaternion)

- `pred_intrinsics.txt` - Camera intrinsics
  - Format: One 3x3 matrix per line (9 values flattened)
  - Contains: `fx 0 cx 0 fy cy 0 0 1`

### 3D Model
- `scene.glb` - 3D scene in glTF 2.0 format
  - Contains mesh/point cloud with textures
  - Includes camera frustums (if enabled)

### Image Data (in subdirectories)
- `depth_maps/` - Depth maps for each frame
- `conf_maps/` - Confidence maps
- `rgb_imgs/` - RGB images
- `dynamic_masks/` - Dynamic object masks

## 🔍 COLMAP Format Requirements

COLMAP format requires these files:
- `cameras.bin` or `cameras.txt` - Camera parameters
- `images.bin` or `images.txt` - Image poses and names
- `points3D.bin` or `points3D.txt` - 3D point cloud

**None of these are generated by MonST3R.**

## ⚠️ About the COLMAP Error

The error you saw earlier:
```
ERROR: Invalid colmap model / workspace
```

This came from a **Blender addon** (`photogrammetry_importer`) that:
1. Tries to auto-detect file formats
2. Attempted to parse the directory as COLMAP format
3. Failed because it's not COLMAP format
4. **This is harmless** - the addon just moves on to try other formats

## 🔄 Converting to COLMAP Format

If you need COLMAP format, you would need to convert from MonST3R's output:

### Conversion Requirements

1. **Camera Parameters** (`cameras.txt`):
   - Convert from `pred_intrinsics.txt` (3x3 K matrix)
   - Extract: `fx, fy, cx, cy` from intrinsics

2. **Image Poses** (`images.txt`):
   - Convert from `pred_traj.txt` (TUM format)
   - Transform quaternion to rotation matrix
   - Extract image filenames from `rgb_imgs/`

3. **3D Points** (`points3D.txt`):
   - Extract from `scene.glb` or depth maps
   - Convert to COLMAP point format

## 📊 Format Comparison

| Format | MonST3R Output | COLMAP Format |
|--------|---------------|---------------|
| Camera Poses | TUM format (`pred_traj.txt`) | `images.txt` or `images.bin` |
| Intrinsics | Text matrix (`pred_intrinsics.txt`) | `cameras.txt` or `cameras.bin` |
| 3D Points | GLB file (`scene.glb`) | `points3D.txt` or `points3D.bin` |
| Images | PNG files (`rgb_imgs/`) | Referenced in `images.txt` |

## ✅ What You Can Use Instead

### For Blender Import:
